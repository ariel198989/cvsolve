# corewise · vision — ראייה ממוחשבת (`/vision`)

Static Hebrew (RTL) marketing site for the Corewise computer-vision axis, presented as a product: "הופכים כל מצלמה טיפשה למצלמה חכמה — לפי הדרישה שלך". Hero → signature "מצלמה רגילה ⇄ מצלמה חכמה" toggle (one generated CCTV frame, detection boxes drawn as HTML/CSS overlays + an event log) → six capabilities (דלת פתוחה/סגורה, אדם חשוד, ספירת אנשים production-ready, זיהוי נפילה as an alert aid, גזם, מדרכה שבורה) → three "בפיתוח" capabilities → proof (Smart City, thinkCV) → how we work → CTA → footer with the internal-skills line and sibling department links. Plain HTML/CSS/vanilla JS, no build step; every asset path is relative so it serves under `https://corewise.co.il/vision/`. Images are `img/*.webp` (≤ 300 KB, lazy-loaded), generated with gpt-image-2 via kie.ai — to regenerate run `bash gen-all.sh` from `img/` (uses `../../gen-image.mjs`, needs `KIE_API_KEY`), then `ffmpeg -i x.png -vf scale=1600:-2 -quality 82 x.webp` and delete the PNGs. WhatsApp CTA goes to Lidor with a site-specific message.
